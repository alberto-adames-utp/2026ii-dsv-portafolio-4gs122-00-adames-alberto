La práctica del Módulo I es un taller: se trabaja con la terminal abierta sobre un repositorio local del proyecto ConSentidos. No produce una página publicada, sino un repositorio con historia propia. Esta página documenta lo que hice y lo que aprendí.

El flujo que practiqué

  • 1

    Crear el repositorio

    git init sobre la carpeta del proyecto, configurar user.name y user.email, y comprobar el estado con git status.

  • 2

    Las tres zonas

    Entender la diferencia entre el directorio de trabajo, el área de preparación y el repositorio: git add y git commit dejan de ser magia.

  • 3

    Historia y diferencias

    git log, git diff y git show para leer qué cambió, cuándo y por qué.

  • 4

    Ramas y fusión

    Crear una rama para una función nueva, trabajar en ella y fusionarla en main sin perder nada.

  • 5

    Deshacer

    Recuperar un archivo borrado por error y revertir un commit: la parte que más tranquilidad da.

  • 6

    Ignorar lo que no se versiona

    El archivo .gitignore y por qué no todo lo que está en la carpeta debe entrar en el repositorio.

Lo que me llevé

  • Lo que más me costó

    Distinguir el área de preparación

    Durante los primeros ejercicios hacía git commit sin git add y no entendía por qué no pasaba nada. Ver el git status después de cada paso fue lo que me lo aclaró.

  • Lo que cambió mi forma de trabajar

    Commits pequeños y con mensaje

    Antes guardaba copias con nombres como final2 y final-bueno. Ahora el historial cuenta qué hice y puedo volver a cualquier punto.
