# Portafolio de Alberto Adames · 4GS122-00

Desarrollo de Software V (8400) · II Semestre 2026
Universidad Tecnológica de Panamá · Centro Regional de Veraguas

queda el tuyo a medida que avanza el semestre: la página personal en la
portada y, en `modulos/`, las prácticas y los laboratorios de cada módulo.

> Consulta este repositorio, pero no lo clones para empezar el tuyo. Tu

## En qué fijarte

- La página personal es el perfil del Laboratorio 1 trasladado a la portada,
  con las rutas ajustadas (`./assets/...` en lugar de `../../assets/...`).
- El índice de entregas distingue lo publicado de lo pendiente, así se ve el
  avance del semestre.
- Todas las páginas pasan el validador del W3C sin errores y escriben los
  elementos vacíos sin barra final (`<br>`, `<img ...>`).
